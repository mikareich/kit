Kit is a collection of code helpers, UI primitives and an opinionated design
language.

This personal project is the consequence of writing the same code over and over
again for many years now. At this point, it is pure muscle memory to configure
biome, write a button or set-up a css theme.

As a developer having DRY (dont-repeat-yourself) wired into my brain, it is like
hitting your toe against the same edge constantly in a procedual way. Time for a
change!

## Setup

Kit uses [shadcn/registry](https://ui.shadcn.com/docs/registry) as a
distribution backend for collected items. The registry is reachable over the
[GitHub repository](https://github.com/mikareich/kit).

The _first_ registry item you add to your codebase must be added through shadcn's
`init` command. Otherwise, shadcn prompts you through the default setup
procedure which is incompatible with this registry.

```bash title="Adding the first item"
bunx --bun shadcn@latest init mikareich/kit/[item]
```

After that you should continue adding items with the `add` command:

```bash title="Adding more items"
bunx --bun shadcn@latest add mikareich/kit/[item]
```
