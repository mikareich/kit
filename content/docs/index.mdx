Kit is a small collection of reusable UI primitives, styles, and utilities. This site documents the same source files that the registry distributes.

## Install from the registry

Add the Kit namespace to a project configured for shadcn:

```bash
bunx shadcn registry add @kit=https://kit.reich.re/r/{name}.json
```

Then install an item:

```bash
bunx shadcn add @kit/button
```
