# kit — Registry for various reusable primitives.

Kit is a collection of code helpers, UI primitives and an opinionated design
language.

This personal project is the consequence of writing the same code over and over
again for many years now. At this point, it is pure muscle memory to configure
biome, write a button or set-up a css theme.

As a developer having DRY (dont-repeat-yourself) wired into my brain, it is like
hitting your toe against the same edge constantly in a procedual way. Time for a
change!

## Tools

- **Bun** manages dependencies and the project lockfile.
- **Next.js** and **React** power the registry website.
- **Fumadocs**, **MDX** and **Fumadocs Story** provide the documentation and
  interactive component examples.
- **Tailwind CSS** and **PostCSS** handle styling, while **shadcn**, **Radix UI**
  and **Class Variance Authority** support the reusable component registry.
- **TypeScript** provides static type checking.
- **Biome** formats and lints the codebase using the shared Kit configuration.
