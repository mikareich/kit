The input primitive accepts all native input properties and adds optional
`prefixIcon` and `suffixIcon` properties for aligned affix icons.

## Installation

Install the input item with the following script:

```bash
bunx shadcn add mikareich/kit/input
```

If this is the first item you install from this registry, replace the `add`
command with `init`.
